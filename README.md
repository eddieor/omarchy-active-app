# Active App

Omarchy bar widget: shows the focused app name in the menu bar.

Plugin id: `eddieor.active-app`

## Install

```bash
omarchy plugin add https://github.com/eddieor/omarchy-active-app.git --enable
omarchy plugin enable eddieor.active-app --section left
```

## Develop

```bash
omarchy plugin validate .
```
